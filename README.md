# Desafio Técnico

É possível encontrar os itens descritos nos desafios no arquivo product.md

Para executar a aplicação, use o script `run.sh` na pasta raiz do projeto, tornando-o executável com o comando `sudo chmod +x run.sh`.

## Requisitos
- Docker e docker compose instalados;
- Acesso a internet.

Após isso, a aplicação ficará disponível em `http://localhost:8089`, onde os endpoints solicitados estarão disponíveis.
1. `/api/conta`
2. `/api/transacao`
